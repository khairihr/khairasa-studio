Background music for the wedding invitation demo (demo/undangan/).

The player looks for a file named:  song.mp3  (in this folder)

Drop the couple's chosen song here as "song.mp3" and the "Buka Undangan"
button will start playing it. Until a file is added, the music button
simply does nothing (no error).

Tip: keep it small (a 2 to 4 MB MP3 is plenty) so the page loads fast,
and make sure you have the right to use the track.
